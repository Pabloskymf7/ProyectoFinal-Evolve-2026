# Datos: fuentes, acceso y generación

Para cada conjunto de datos documentad:
- nombre de la fuente y URL;
- fecha de consulta/descarga;
- frecuencia, cobertura temporal, territorio y unidades;
- formato y procedimiento reproducible de descarga;
- condiciones de uso y atribución;
- transformaciones realizadas y limitaciones.

No guardéis credenciales, datos personales ni ficheros que no deban compartirse. Para las primeras pruebas, preferid muestras permitidas o datos sintéticos.
